FAQ

What does "AI-friendly" mean?

Many companies screen resumes with software (ATS) and, more and more, AI. Every design here uses real text, standard headings like Experience and Education, and a clear reading order, so those tools read your details correctly. Designs tagged ATS-safe use a single column, the safest choice for big company portals.

Does the AI make things up?

It's told to use only what you write. If a number would make a point stronger, it leaves a marker like [add number] for you to fill in. Always read the result before you send it.

Which file should I send?

Send the PDF when you email or upload a resume. Use Word if a portal asks for .docx or you want to edit offline. Use plain text when a portal asks you to paste your resume into a box.

Can I make it on my phone?

Yes. The builder works on any phone browser, and downloads open in Google Docs, Word or any PDF viewer.

Is my data saved anywhere?

Your details stay in your own browser so you can come back later. Clear them anytime with Start blank.
